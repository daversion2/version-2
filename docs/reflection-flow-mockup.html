Unified reflection flow — practices & challenges

One identical five-question flow for both contexts. Toggle between a practice and a challenge — only the header and accent change; every question, input, and transition is the same. All questions are skippable; the flow logs either way.

What each question is doing

    Design notes for this mockup
    · Q3 is a two-tap reality check instead of a textarea — the example of a talk-you-out-of-it thought lives in the helper line under the question, and answering "No, not really" opens an optional reframe ("What's the truer thought?"), the classic CBT move. Easy to flatten back to a plain textarea if you prefer.
    · Q5 is a single line with an 80-character cap to force one concrete takeaway; it's pinned at the top of the summary so it reads like the headline of the rep.
    · The close ✕ and every Skip work exactly like the current challenge flow.
