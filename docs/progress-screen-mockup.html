Design decisions baked into this mockup

Override Score (re-based)

  • Weekly and filter-independent, as today — but recalculated as all practice + challenge completions, dropping the arena gate that currently excludes untagged reps.
  • Week-over-week delta folds in here (the separate WeekOverWeek card is cut).

Training Volume (replaces Discipline Map)

  • Card grid, 2-up, grouped Activate / Calm / Restrain with group rollups in the header. Only groups with adopted practices render; custom practices get a "Custom" group.
  • Reps + points lead; metrics are secondary. Metrics aggregate only reps where the value was logged — skipped sliders are excluded from totals/averages, never counted as zero.
  • Aggregation is catalog-driven via TrackingField type: duration → sum, number → average, choice → mode ("mostly walk"). Admin-added practices get stats for free.
  • Zero-rep adopted practices show as muted Untrained cards — keeps the avoidance-surfacing job the Discipline Map did.
  • Tap a card → practice/habit detail (was: ArenaDetail).

Challenges strip

  • Replaces the Practices-vs-Challenges breakdown card: completions, points, avg actual difficulty for the period.

Training Quality

  • Hard moments pushed through = completions with hitHardMoment from the shared 5-question CBT reflection.
  • Challenging % = share of practice reps rated "challenging" vs "easy"; comparison line vs the previous equal-length period.

Kept / cut

  • Kept: filter chips, hero stats (Total actions renamed Completions, XP renamed Points), trend chart, calendar → day detail.
  • Personal records reworked to visceral, metric-backed records (longest sit, coldest plunge, longest fast).
  • Cut: Goals entry row (outcome goals deferred), Discipline Map, WeekOverWeek card, Period Breakdown card.

Build notes

  • All data comes from completionLogs already fetched for the period — the grid is client-side aggregation, no new indexes.
  • Denormalize practice_id onto new completion logs; resolve older logs via habit → practice_id.
  • Entirely JS — shippable as an OTA update.
